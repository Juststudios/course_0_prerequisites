# Course 0: Exercises Index & Practice Guide

Welcome to the practice and self-assessment section for **Course 0: AI Agent Prerequisites**.

## 4-Tier Pedagogical Progression

Every topic in Course 0 is reinforced across four progressive tiers of cognitive mastery:

1. **Tier 1 (Recall)**: Validates retention of key terms, syntax, rules, and failure semantics.
2. **Tier 2 (Debugging)**: Diagnoses broken, unsafe, or inefficient agent code snippets and implements robust fixes.
3. **Tier 3 (Application)**: Builds practical, production-grade agent utilities from specification.
4. **Tier 4 (Challenge)**: Synthesizes multiple system components into cohesive, end-to-end agent architectures.
