# Applied Python Programming & Data Tools

Welcome to the Python programming workspace. This repository contains learning materials and source code taking students from beginner Python programming all the way to advanced numerical computing, tabular data wrangling, and scientific visualization.

---

## Workspace Navigation

### 1. Foundational Python Lessons
* `lesson.py`: Introduction to Python syntax, variables, conditionals, loops, and basic functions.
* `game.py`: Interactive Tic-Tac-Toe console game demonstrating 2D lists and state verification.
* `nmpy.py`: Exploration of multi-dimensional arrays (1D, 2D, 3D) and axis operations.
* `pan.md`: Comprehensive instructor teaching guide for Pandas 101.
* `pans.md`: Student handbook and reference for Pandas operations.

---

### 2. Complete Data Tools Curriculum: `python-data-tools/`
The complete, structured teaching package is located in **[`python-data-tools/`](./python-data-tools/README.md)**:

* **[NumPy Lessons (`python-data-tools/lessons/01_numpy/`)](./python-data-tools/lessons/01_numpy/README.md)**
  * Array creation, dimensions, slicing, vectorization, statistics, and masking.
* **[Pandas Lessons (`python-data-tools/lessons/02_pandas/`)](./python-data-tools/lessons/02_pandas/README.md)**
  * Series, DataFrames, CSV loading, filtering, data cleaning, and grouped aggregations (`groupby`).
* **[Matplotlib Lessons (`python-data-tools/lessons/03_matplotlib/`)](./python-data-tools/lessons/03_matplotlib/README.md)**
  * Core charts (line, bar, scatter, hist), styling, annotations, and multi-panel subplots.
* **[Integrated Project: Student Academic Performance Analysis (`python-data-tools/projects/student_performance_analysis/`)](./python-data-tools/projects/student_performance_analysis/README.md)**
  * End-to-end data pipeline combining Pandas, NumPy, and Matplotlib.
* **[Independent Capstone: Predictive Maintenance (`python-data-tools/capstone/`)](./python-data-tools/capstone/README.md)**
  * Real-world engineering fleet health audit with full grading rubric.
* **[Final Assessment (`python-data-tools/assessment/`)](./python-data-tools/assessment/FINAL_ASSESSMENT.md)**
  * Conceptual questions, code reading, debugging challenges, and practical tests.
* **[Solutions & Answer Keys (`python-data-tools/solutions/`)](./python-data-tools/solutions/)**
  * Complete reference implementations for all exercises, projects, and exams.

---

## Quickstart

```bash
# Install dependencies
pip install -r requirements.txt

# Run the flagship student performance analysis pipeline
python python-data-tools/projects/student_performance_analysis/analysis.py

# Run the capstone reference solution
python python-data-tools/solutions/capstone_solution.py
```
